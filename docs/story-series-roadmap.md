# 穿越·史记 · 故事系列总路线图

> 把整部《史记》130 卷拆成 **10 个大系列**（一个时代/主题）。每个系列进入后**可选不同主角，体验各自遵循史实的故事线**。系统少女**青月**贯穿全程。
> 生成方法见 `.trae/skills/ink-story-writing/SKILL.md`；素材唯一事实源为 `src/react-app/data/classics/chapters/<卷号>.ts`。

## 一、结构模型：系列 → 主角线(视角) → 章/幕

| 层 | 概念 | 映射 |
|----|------|------|
| **系列** | 一个时代（春秋、楚汉） | `data/series.ts` 的 `SeriesDef`；选择页按 `series` id 分组 |
| **主角线(视角)** | 可选主角，各一条弧线（项羽线/刘邦线） | `Storyline.perspectives[]` 里的 `Perspective`（characterId + storyKey） |
| **章/幕** | 主角一生的一段（鸿门/垓下） | 该主角 storyKey 对应 ink 内的 knot/幕 |

- **✅ UI 已支持**：`StorySelectPage` 对每个 perspective 渲染一个「以X视角」按钮。多主角 = 纯数据：给一张 Storyline 卡的 `perspectives` 加多条即可。
- **多主角系列**（春秋/战国/楚汉…）：一个系列下多张卡或多 perspective；同一事件在不同主角线里从不同视角、不同抉择呈现，皆遵史实（项羽线选「杀不杀刘邦」，刘邦线选「如何脱身」）。
- **单线序列系列**（上古/商/西周）：一条编年主线，episodic 多卡即可。
- **粒度取舍**：长生涯主角（项羽/勾践/韩信）宜「一条多幕弧线」；同代群英（战国四公子）宜「一卡多 perspective」或「按人多卡」。
- **分章按成长弧线，不是大事记**（skill §3.2）：一条主角线先定**人物母题与致命弱点**，再排 **6–10 幕成长节拍**（起点缺陷→试炼→转变→巅峰→弱点显现→崩解→顿悟），每幕＝一个内在成长节点×一场历史事件。史事服务人物刻画，切忌"1 节=1 章"平铺。样板见 `docs/series-chuhan-plan.md`。

## 二、总原则
- 一个系列 **12–20 章**（跨多个主角线累计）；高影响力**典故独立成章**；史料稀薄/纯表志的节折叠为青月过场或彩蛋。
- **叙事金矿 = 本纪(1–12) + 世家(31–60) + 列传(61–130)**。
- **表(13–22)不做**（编年表）；**书(23–30)不做独立系列**，河渠/封禅/平准书折入相关系列做彩蛋。
- 章按**玩家亲历顺序**排。一个事件散见多卷时交叉引用，以主角所在卷为骨。

## 五、地基：并发生产的工程结构（已就位）

为支持多对话并行、互不冲突，**注册文件已全部按系列拆分为目录 + index 汇总**：

```
data/
  series.ts                        # 🆕 十大系列注册表（SeriesDef）
  storylines/
    index.ts                       # 合并各系列 + STORYLINE_MAP/getStoryline/TOTAL_PERSPECTIVES
    _series.ts                     # withSeries() 盖章助手
    wudi.ts  chuhan.ts             # 每系列一份
  stories/inkStories/
    index.ts  wudi.ts  chuhan.ts   # 剧本 + deaths registry，每系列一份
  sceneAssets/
    index.ts                       # 合并 SPRITES/BACKGROUNDS + getSprite/getBackground
    base.ts                        # 青月 + 楚汉卡池 + 已完成系列(五帝夏)资产
  achievements/
    index.ts  base.ts              # 合并 ACHIEVEMENTS + getAchievement
```

**新增一个系列的落地流程（另一对话领取后）**：
1. 建 `storylines/<series>.ts`（`withSeries("<series>", [...卡片...])`），在 `storylines/index.ts` 加一行 import+展开。
2. 建 `stories/inkStories/<series>.ts`（.ink 导入 + deaths），index 加一行。
3. 建 `sceneAssets/<series>.ts`（导出 `<series>Sprites`/`<series>Backgrounds`），index 合并。
4. 建 `achievements/<series>.ts`（导出 `<series>Achievements`），index 合并。
5. `.ink` 文件写进 `stories/ink/`。
6. 各系列只碰**自己的文件** + 每个 index 加一行 → 冲突面最小；`series.ts` 的对应条目去掉 `comingSoon`。

**类型/枚举**：`Storyline.series` 必填（`withSeries` 自动盖）；`Era` 已含 `wudi/shang/western_zhou/spring_autumn/warring_states/qin/chu_han/western_han/mixed`。

**选择页**：`StorySelectPage` 从 `data/series.ts` 读 SERIES，按 `sl.series === series.id` 分组；`_ink` 故事跳过解锁门禁；非卡池主角名走 `sceneAssets` 兜底。
