## 0. 本版变更说明（相对 v0.1 / v1.0）

本版的目标是**让文档与真实仓库一致**，并修掉旧方案里在编码时会咬人的问题。

| 项 | 旧文档 | v2.0 定稿 | 原因 |
|---|---|---|---|
| 部署 / 后端 | Vercel + Vercel Edge Function | **Cloudflare Workers + Hono**（仓库现状） | 仓库就是 `vite-react + Hono + Wrangler` 模板，不再走 Vercel |
| AI 代理 | `vercel/api/claude-proxy.ts` 透传 | **Hono `/api/hint` 路由 + 鉴权/限流/参数白名单** | 防止公开站点被当免费 Claude 网关刷爆 |
| React | 18.x | **19.2.x**（仓库现状） | 与 `package.json` 对齐 |
| 构建 | Vite 5 | **Vite 7**（仓库现状） | 同上 |
| 可视化 | v0.1=ECharts / v1.0=D3 互相矛盾 | **D3.js 7** | 关系图需要力导向自定义，统一为 D3 |
| MVP 范围 | v0.1=韩信 7 章 / v1.0=鸿门宴 3 视角 互相矛盾 | **韩信单线 7 章打底 + 鸿门宴项羽 1 视角** | 先证核心循环，再加多视角种子 |
| 保底 | v0.1=16 抽 / v1.0=10 抽 互相矛盾 | **15 抽保底，第 16 抽必出新角色** | 统一为 v0.1 的产品语义 |
| 重复奖励 | v0.1=1 碎片 / v1.0=30 碎片 | **重复 = 1 记忆碎片** | 统一为 v0.1 |
| ink 加载 | v1.0 既说 `import()` 又说 `public/ fetch` | **统一为运行时 fetch `public/ink/*.json`** | 不进主 bundle，避免内容更新触发整包重打 |
| 存档 | Zustand 与 SaveManager 双写 | **唯一事实源 = Zustand persist**，ink 存档内嵌其中 | 消除双写不一致 |
| 成就触发 | ink EXTERNAL 与 JS 轮询两套并存 | **唯一权威 = ink `EXTERNAL triggerAchievement`** | 单一触发路径，避免重复/漏触 |
| 变量读取 | `getVariables()` 硬编码 3 个变量名 | **泛型快照，读 ink 全量变量** | 换故事线不需要改引擎 |
| 对话署名 | bulk 收集导致只剩最后一个 speaker | **按行（segment）模型，逐句携带 speaker** | 修复多说话人被合并的 bug |
| 抽卡保底计数 | 局部 `pity` 从不写回 store | **每抽后持久化 `pityCount`，出新角色才清零** | 修复保底失效 bug |

> ⚠️ **现状提示**：本文档第 2 节之后描述的是**目标架构**。截至本版，仓库只有 `src/react-app`（Vite React 模板）+ `src/worker/index.ts`（一个 Hono demo 路由），下列目录与依赖**尚未落地**，第 16 节给出落地清单。

## 3. 前后端边界与请求流

单 Worker 同时托管静态 SPA 与 API（`wrangler.json` 的 `assets.not_found_handling: single-page-application` 已配置好 SPA 回退）。

```
浏览器 (React SPA, Cloudflare CDN)
   │  静态资源 / ink JSON / 图片 / 字体   → Cloudflare Assets（同一 Worker 的 assets 绑定）
   │  POST /api/hint                      → Hono Route（鉴权→限流→转发 Anthropic）
   ▼
Cloudflare Worker (src/worker/index.ts, Hono)
   ├── app.route('/api/hint', hint)       → Anthropic Messages API（密钥仅存 Worker Secret）
   └── 其余路径                            → 交给 assets（SPA index.html）
```

```typescript
// src/worker/index.ts —— 在现有 demo 上扩展
import { Hono } from "hono";
import { hint } from "./routes/hint";

const app = new Hono<{ Bindings: Env }>();

app.get("/api/health", (c) => c.json({ ok: true }));
app.route("/api/hint", hint);
// 非 /api 路径由 wrangler assets(single-page-application) 接管，无需在此处理

export default app;
```

> 设计原则：**前端永远不直连 `api.anthropic.com`**，密钥只存在 Worker Secret（`wrangler secret put ANTHROPIC_API_KEY`），见第 11 节。

### 4.2 inkRunner（segment 模型，修复 speaker 丢失）

关键修复：**不再把整段文本 bulk 成一个 block**，而是按 `Continue()` 的每一行生成一个 `segment`，每个 segment 携带自己的 `speaker` / `classicalHint`。死亡标签出现即停。

```typescript
// src/react-app/engine/inkRunner.ts
import { Story } from "inkjs";

export interface Segment {
  text: string;
  speaker: string;             // 该行的 #SPEAKER（逐行解析，互不覆盖）
  classicalHint?: string;      // 该行的 #CLASSICAL_HINT
}

export interface InkState {
  segments: Segment[];
  choices: { index: number; text: string }[];
  death: { reason: string; classical: string; analysis: string } | null;
  isEnded: boolean;
  variables: Record<string, unknown>;   // 全量快照，不硬编码
}

export interface InkCallbacks {
  onAchievement?: (id: string) => void;
  onBGM?: (track: string) => void;
  onCharacter?: (id: string, expr: string, pos: string) => void;
  onHideCharacter?: (id: string) => void;
  onBackground?: (bg: string) => void;
}

export class InkRunner {
  private story: Story;

  constructor(inkJson: object, cb: InkCallbacks = {}) {
    this.story = new Story(inkJson);
    this.story.BindExternalFunction("triggerAchievement", (id: string) => cb.onAchievement?.(id));
    this.story.BindExternalFunction("playBGM", (t: string) => cb.onBGM?.(t));
    this.story.BindExternalFunction("showCharacter", (id: string, e: string, p: string) => cb.onCharacter?.(id, e, p));
    this.story.BindExternalFunction("hideCharacter", (id: string) => cb.onHideCharacter?.(id));
    this.story.BindExternalFunction("changeBackground", (bg: string) => cb.onBackground?.(bg));
  }

  advance(): InkState {
    const segments: Segment[] = [];
    let death: InkState["death"] = null;

    while (this.story.canContinue) {
      const line = this.story.Continue().trim();
      const tags = this.parseTags(this.story.currentTags);

      if (tags.DEATH === "true") {
        death = {
          reason: tags.DEATH_REASON ?? "",
          classical: tags.DEATH_CLASSICAL ?? "",
          analysis: tags.DEATH_ANALYSIS ?? "",
        };
        break; // 死亡：停止收集
      }
      if (line) {
        segments.push({
          text: line,
          speaker: tags.SPEAKER ?? "",
          classicalHint: tags.CLASSICAL_HINT,
        });
      }
    }

    return {
      segments,
      choices: this.story.currentChoices.map((c, i) => ({ index: i, text: c.text })),
      death,
      isEnded: !this.story.canContinue && this.story.currentChoices.length === 0 && !death,
      variables: this.snapshotVariables(),
    };
  }

  choose(index: number): InkState {
    this.story.ChooseChoiceIndex(index);
    return this.advance();
  }

  /** 泛型快照：读取 ink 全部 global 变量，无硬编码（换故事线零改动） */
  private snapshotVariables(): Record<string, unknown> {
    const out: Record<string, unknown> = {};
    for (const name of this.story.variablesState as Iterable<string>) {
      out[name] = this.story.variablesState[name];
    }
    return out;
  }

  private parseTags(raw: string[]): Record<string, string> {
    const tags: Record<string, string> = {};
    for (const t of raw) {
      const i = t.indexOf(":");
      if (i === -1) continue;
      tags[t.slice(0, i).trim()] = t.slice(i + 1).trim();
    }
    return tags;
  }

  getSaveState(): string { return this.story.state.ToJson(); }
  loadSaveState(json: string): void { this.story.state.LoadJson(json); }
}
```

> `variablesState` 的可迭代性视 inkjs 版本而定；若该版本不支持迭代，则在 `common.ink` 维护一个 `LIST`/约定的变量清单，或在编译期由 `build-ink.mjs` 提取变量名注入。无论哪种，引擎层都不写死具体变量名。

## 6. 状态管理与存档（单一事实源）

**所有持久化数据只走 Zustand `persist` → `localStorage['shiji-user-progress']`**。删除 v1.0 里独立的 `SaveManager` 双写层。ink 存档作为 `PerspectiveProgress.inkSaveState` 内嵌其中，避免两份存档不一致。

```typescript
// store/userStore.ts
import { create } from "zustand";
import { persist } from "zustand/middleware";
import type { UserProgress, PerspectiveProgress } from "../types/progress";
import { createInitialProgress } from "./initial";

interface UserStore {
  progress: UserProgress;
  // 资源
  spendGachaTicket: (n: number) => boolean;
  addFragment: (n: number) => void;
  unlockCharacter: (id: string) => void;
  setPity: (n: number) => void;
  pushPull: (p: import("../types/progress").GachaPull) => void;
  // ink 存档（唯一入口）
  saveInk: (storyId: string, charId: string, inkJson: string) => void;
  loadInk: (storyId: string, charId: string) => string | undefined;
  patchPerspective: (storyId: string, charId: string, patch: Partial<PerspectiveProgress>) => void;
  // 成就
  unlockAchievement: (id: string, points: number) => boolean;  // 返回是否首次解锁
}

export const useUserStore = create<UserStore>()(
  persist(
    (set, get) => ({
      progress: createInitialProgress(),

      spendGachaTicket: (n) => {
        if (get().progress.gachaTickets < n) return false;
        set((s) => ({ progress: { ...s.progress, gachaTickets: s.progress.gachaTickets - n } }));
        return true;
      },
      addFragment: (n) => set((s) => ({ progress: { ...s.progress, fragments: s.progress.fragments + n } })),
      unlockCharacter: (id) => set((s) =>
        s.progress.gacha.ownedCharacters.includes(id) ? s : {
          progress: { ...s.progress, gacha: { ...s.progress.gacha, ownedCharacters: [...s.progress.gacha.ownedCharacters, id] } },
        }),
      setPity: (n) => set((s) => ({ progress: { ...s.progress, gacha: { ...s.progress.gacha, pityCount: n } } })),
      pushPull: (p) => set((s) => ({
        progress: { ...s.progress, gacha: { ...s.progress.gacha,
          totalPulls: s.progress.gacha.totalPulls + 1,
          pullHistory: [p, ...s.progress.gacha.pullHistory].slice(0, 100) } },
      })),

      saveInk: (storyId, charId, inkJson) => set((s) => upsertPerspective(s.progress, storyId, charId, { inkSaveState: inkJson })),
      loadInk: (storyId, charId) => get().progress.storylines[storyId]?.[charId]?.inkSaveState,
      patchPerspective: (storyId, charId, patch) => set((s) => upsertPerspective(s.progress, storyId, charId, patch)),

      unlockAchievement: (id, points) => {
        if (get().progress.achievements.unlocked.includes(id)) return false;
        set((s) => ({ progress: { ...s.progress,
          points: s.progress.points + points,
          achievements: { ...s.progress.achievements, unlocked: [...s.progress.achievements.unlocked, id] } } }));
        return true;
      },
    }),
    { name: "shiji-user-progress", version: 1 }
  )
);

function upsertPerspective(p: UserProgress, storyId: string, charId: string, patch: Partial<PerspectiveProgress>) {
  const prevStory = p.storylines[storyId] ?? {};
  const prev = prevStory[charId] ?? { isStarted: false, isCompleted: false, completedNodes: 0, deathCount: 0 };
  return { progress: { ...p, storylines: { ...p.storylines, [storyId]: { ...prevStory, [charId]: { ...prev, ...patch } } } } };
}
```

### 7.1 useInkStory（统一 fetch public/ink，恢复存档）

```typescript
// hooks/useInkStory.ts
import { useState, useEffect, useRef, useCallback } from "react";
import { InkRunner, type InkState } from "../engine/inkRunner";
import { useUserStore } from "../store/userStore";
import { useAchievement } from "./useAchievement";

export function useInkStory(storyId: string, charId: string) {
  const [state, setState] = useState<InkState | null>(null);
  const [scene, setScene] = useState({ background: "default", characters: {} as Record<string, { expression: string; position: string }> });
  const [loading, setLoading] = useState(true);
  const runner = useRef<InkRunner | null>(null);
  const { triggerAchievement } = useAchievement();
  const { saveInk, loadInk } = useUserStore();

  useEffect(() => {
    let alive = true;
    (async () => {
      setLoading(true);
      // 统一策略：运行时 fetch，不打进 bundle
      const inkJson = await fetch(`/ink/${storyId}/${charId}.json`).then((r) => r.json());
      if (!alive) return;
      runner.current = new InkRunner(inkJson, {
        onAchievement: triggerAchievement,
        onCharacter: (id, expression, position) =>
          setScene((p) => ({ ...p, characters: { ...p.characters, [id]: { expression, position } } })),
        onHideCharacter: (id) =>
          setScene((p) => { const c = { ...p.characters }; delete c[id]; return { ...p, characters: c }; }),
        onBackground: (background) => setScene((p) => ({ ...p, background })),
      });
      const saved = loadInk(storyId, charId);
      if (saved) runner.current.loadSaveState(saved);
      setState(runner.current.advance());
      setLoading(false);
    })();
    return () => { alive = false; };
  }, [storyId, charId]);

  const persist = useCallback(() => {
    if (runner.current) saveInk(storyId, charId, runner.current.getSaveState());
  }, [storyId, charId, saveInk]);

  const makeChoice = useCallback((i: number) => {
    if (!runner.current) return;
    setState(runner.current.choose(i));
    persist();
  }, [persist]);

  const advance = useCallback(() => {
    if (!runner.current) return;
    setState(runner.current.advance());
    persist();
  }, [persist]);

  return { state, scene, loading, makeChoice, advance };
}
```

### 7.2 DialogueBox（逐句署名，逐字打印）

```typescript
// pages/Play/DialogueBox.tsx
import { useEffect, useState } from "react";
import { usePlayStore } from "../../store/playStore";
import type { Segment } from "../../engine/inkRunner";

const SPEED = { slow: 60, normal: 30, fast: 10 };

export default function DialogueBox({ segments, onAllDone }: { segments: Segment[]; onAllDone: () => void }) {
  const { textSpeed } = usePlayStore();
  const [idx, setIdx] = useState(0);          // 当前播放到第几个 segment
  const [shown, setShown] = useState("");
  const [done, setDone] = useState(false);

  const seg = segments[idx];

  useEffect(() => {
    setShown(""); setDone(false);
    if (!seg) return;
    let i = 0;
    const t = setInterval(() => {
      i++;
      setShown(seg.text.slice(0, i));
      if (i >= seg.text.length) { setDone(true); clearInterval(t); }
    }, SPEED[textSpeed]);
    return () => clearInterval(t);
  }, [idx, seg, textSpeed]);

  if (!seg) return null;

  const next = () => {
    if (!done) { setShown(seg.text); setDone(true); return; } // 先补全
    if (idx < segments.length - 1) setIdx(idx + 1);
    else onAllDone();                                          // 播完交还控制权
  };

  return (
    <div className="dialogue-box" onClick={next}>
      {seg.speaker && <div className="speaker-name">{seg.speaker}</div>}
      <div className="dialogue-text">{shown}{!done && <span className="cursor">|</span>}</div>
      {done && <div className="continue-hint">▼ 点击继续</div>}
    </div>
  );
}
```

## 8. 抽卡系统实现（修复版）

修复 v1.0 两个 bug：①保底计数从不写回 store；②"到 10 必清零"与"出新才清零"语义不符。本版语义：**连续 15 抽没出新角色，第 16 抽强制出新；一旦出新，pity 清零并持久化**。

```typescript
// data/gachaPools.ts
export interface GachaRules {
  pityAt: number;                 // 15：达到该值后下一抽强制出新
  fragmentsOnDuplicate: number;   // 1：重复奖励碎片
}
export interface GachaPoolCharacter { characterId: string; weight: number; isLimited?: boolean }
export interface GachaPool { id: string; name: string; characters: GachaPoolCharacter[]; rules: GachaRules }

export const CURRENT_POOL: GachaPool = {
  id: "chu_han_1", name: "楚汉争霸·首发",
  rules: { pityAt: 15, fragmentsOnDuplicate: 1 },
  characters: [ /* 8 角色，weight 均等（无星级） */ ],
};
```

```typescript
// hooks/useGacha.ts
import { useUserStore } from "../store/userStore";
import { CURRENT_POOL } from "../data/gachaPools";

export interface PullResult { characterId: string; isDuplicate: boolean }

export function useGacha() {
  const { progress, spendGachaTicket, addFragment, unlockCharacter, setPity, pushPull } = useUserStore();

  function pull(count: 1 | 10): PullResult[] {
    if (!spendGachaTicket(count)) throw new Error("抽卡券不足");

    const owned = new Set(progress.gacha.ownedCharacters);
    let pity = progress.gacha.pityCount;          // 从持久化值开始
    const results: PullResult[] = [];

    for (let i = 0; i < count; i++) {
      const forceNew = pity >= CURRENT_POOL.rules.pityAt;   // 第 16 抽（计数到 15）强制出新
      const char = draw(owned, forceNew);
      const isDuplicate = owned.has(char.characterId);

      if (isDuplicate) {
        addFragment(CURRENT_POOL.rules.fragmentsOnDuplicate);
        pity++;                                  // 没出新，累加
      } else {
        unlockCharacter(char.characterId);
        owned.add(char.characterId);
        pity = 0;                                // 出新才清零
      }

      results.push({ characterId: char.characterId, isDuplicate });
      pushPull({ timestamp: Date.now(), characterId: char.characterId, isDuplicate,
        fragmentsGained: isDuplicate ? CURRENT_POOL.rules.fragmentsOnDuplicate : 0 });
    }

    setPity(pity);                                // ★ 关键：写回持久化（v1.0 缺这步）
    return results;
  }

  function draw(owned: Set<string>, forceNew: boolean) {
    const pool = CURRENT_POOL.characters;
    const unowned = pool.filter((c) => !owned.has(c.characterId));
    if (forceNew && unowned.length > 0) return weighted(unowned);
    if (unowned.length === 0) return weighted(pool);  // 全收集后回退为纯抽碎片
    return weighted(pool);
  }

  function weighted(list: typeof CURRENT_POOL.characters) {
    const total = list.reduce((s, c) => s + c.weight, 0);
    let r = Math.random() * total;
    for (const c of list) { r -= c.weight; if (r <= 0) return c; }
    return list[list.length - 1];
  }

  return { pull };
}
```

> 注：`Math.random()` 在浏览器端运行（不是 Worker），无 SSR 确定性约束，可用。若未来要服务端发奖防作弊，再迁移到 Worker + crypto。

## 11. AI 集成（Cloudflare Worker + Hono 代理）

唯一 AI 场景（MVP）：**游戏内智能提示**。前端调自家 `/api/hint`，Worker 鉴权 + 限流 + 参数白名单后再转发 Anthropic。**密钥只在 Worker Secret**。

```typescript
// src/worker/routes/hint.ts
import { Hono } from "hono";
import { rateLimit } from "../lib/rateLimit";

const HINT_SYSTEM = `你是《史记》历史顾问，辅助沉浸式历史游戏。
规则：1) 不得直接说哪个选项正确；2) 用启发式问题引导；3) 可引一句史记原文但不解释；4) ≤80字；5) 古风但易懂。
禁止：直说"选A"、剧透历史结果。`;

export const hint = new Hono<{ Bindings: Env }>();

hint.post("/", async (c) => {
  // 1) 来源校验：只允许本站
  const origin = c.req.header("Origin") ?? "";
  const allowed = (c.env.ALLOWED_ORIGIN ?? "").split(",");
  if (allowed.length && !allowed.includes(origin)) return c.json({ error: "forbidden" }, 403);

  // 2) 限流（KV，按 IP）
  const ip = c.req.header("CF-Connecting-IP") ?? "anon";
  if (!(await rateLimit(c.env.RL_KV, ip, 20, 60))) return c.json({ error: "rate_limited" }, 429);

  // 3) 参数白名单（前端不能自定义 model/max_tokens/system，杜绝被当通用网关）
  const body = await c.req.json().catch(() => ({}));
  const { character, situation, choices, classicalHint } = body as Record<string, string>;
  if (!situation || !Array.isArray(body.choices)) return c.json({ error: "bad_request" }, 400);

  const res = await fetch("https://api.anthropic.com/v1/messages", {
    method: "POST",
    headers: {
      "content-type": "application/json",
      "x-api-key": c.env.ANTHROPIC_API_KEY,
      "anthropic-version": "2023-06-01",
    },
    body: JSON.stringify({
      model: "claude-sonnet-4-6",   // 服务端固定，前端无法更改
      max_tokens: 200,
      system: HINT_SYSTEM.replace("{character}", character ?? "历史人物"),
      messages: [{ role: "user", content:
        `情境：${situation}\n可选：${(choices as unknown as string[]).join(" | ")}\n原文线索：${classicalHint ?? ""}\n请给一个引导性提示。` }],
    }),
  });
  if (!res.ok) return c.json({ error: "upstream", status: res.status }, 502);
  const data = await res.json();
  return c.json({ hint: data.content?.[0]?.text ?? "" });
});
```

```typescript
export async function rateLimit(kv: KVNamespace, key: string, limit: number, windowSec: number) {
  const k = `rl:${key}`;
  const cur = parseInt((await kv.get(k)) ?? "0", 10);
  if (cur >= limit) return false;
  await kv.put(k, String(cur + 1), { expirationTtl: windowSec });
  return true;
}
```

## 12. 字体与资源策略

CJK 字体是首屏性能与"缺字"风险的大头，必须显式处理：

- **子集化**：用 `fontmin` / `subset-font` 按**实际出现的字符集**（扫描所有 `.ink` + `data/*.ts` + UI 文案）生成子集，而非按字重全量。文言文含生僻人名地名，必须以内容驱动子集，避免缺字豆腐块。
- **格式**：输出 `woff2`，`font-display: swap`，正文 `Noto Serif SC`、UI `Noto Sans SC`。
- **构建集成**：`scripts/build-fonts.mjs` 在 `build` 前运行，产物入 `public/fonts/`，由 Cloudflare CDN 缓存。
- **分享卡 Canvas 字体**：Canvas 绘制依赖字体已加载，使用 `document.fonts.ready` 等待后再绘制，否则分享卡会回退系统字体。
- **图片**：角色立绘/背景统一 `webp`，`loading="lazy"`、`decoding="async"`；进入故事线前 `preload` 该线背景图。大图后续可迁 Cloudflare R2/Images。

## 13. 内容生产管线

- **单元**：`vitest` 覆盖纯逻辑——`useGacha` 保底/碎片、`inkRunner.advance` 的 segment 与 death 解析、成就去重。这些是最容易回归的地方。

## 16. 落地清单（从模板到目标态）

仓库当前 = Cloudflare vite-react 模板。按序执行即可补齐：

1. **装依赖**
   ```bash
   npm i inkjs zustand react-router-dom d3 framer-motion lucide-react
   npm i -D @types/d3 tailwindcss autoprefixer postcss vitest @testing-library/react glob
   # 注意验证 framer-motion 对 React 19 的兼容；不兼容则暂用 CSS 动画
   ```
2. **建目录**：按 §2 在 `src/react-app/` 下创建 `pages/components/engine/store/data/hooks/services/types/utils`，在 `src/` 下建 `ink/`，根目录建 `scripts/`。
3. **设计令牌**：把色彩/字体/间距/层级变量写进 `src/react-app/index.css` 的 `:root`（沿用 v1.0 §3 的令牌值）。
4. **路由**：改写 `src/react-app/App.tsx` 为 React Router（`/`、`/gacha`、`/archive`、`/achieve`、`/play/:storyId/:charId`、`/panorama/:storyId`）。
5. **Worker**：在 `src/worker/` 加 `routes/hint.ts` + `lib/rateLimit.ts`，`index.ts` 挂载；`wrangler.json` 加 KV 绑定与 `ALLOWED_ORIGIN`；`wrangler secret put ANTHROPIC_API_KEY`；`npm run cf-typegen`。
6. **构建脚本**：`scripts/build-ink.mjs`、`scripts/build-fonts.mjs`，在 `package.json` 的 `build` 前串联（`"build": "node scripts/build-ink.mjs && node scripts/build-fonts.mjs && tsc -b && vite build"`）。
7. **Vite 分包**：在 `vite.config.ts` 补 `manualChunks`（注意与 `@cloudflare/vite-plugin` 兼容）。
8. **CI 校验**：把 §13 的内容一致性校验接进 `npm run check`。
