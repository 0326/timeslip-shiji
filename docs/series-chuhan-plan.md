# 系列工作包 · 楚汉相争（chuhan）

> 可直接派发给一个对话独立生产。方法见 `.trae/skills/ink-story-writing/SKILL.md`（尤其 §3.2 主角成长弧线、§5 按系列注册）。
> series id = `chuhan`；核心卷 **7,8,92,55,48,89,90,91**（均已核查完整）。

## 设计原则：一条线 = 一个人的成长弧线，不是历史大事记
每条主角线**先定人物母题与致命弱点**，再排 6–8 幕成长节拍——**每一幕 = 一个内在成长节点 × 一场历史事件**（史事是舞台，人物是主体）。玩家进「楚汉相争」→ 选一条主角线 → 走这个人从起点到结局的完整蜕变。同一事件（鸿门宴）在不同线里是**不同成长节点**（项羽的"妇人之仁" vs 刘邦的"能屈能伸" vs 张良的"运筹"）。

- 每条线 = 一张卡（focusCharacter=主角）= 一个多幕 ink（storyKey `<主角>:chuhan`，幕=knot）。
- ⭐=招牌典故；🔁=多视角共享事件；每幕「抉择」都考验人物母题，不只是史实对错。

## 幕内深度与玩法（见 `docs/gameplay-extensibility.md`）
每幕不是单一抉择，而是 **2–4 个有分量抉择 + 跨幕状态 + 可选小游戏 + 多结局**：
- **跨幕状态 VAR（量化母题/弱点，贯穿全弧）**：
  - 韩信：`ren`(忍) / `zhiyu`(知遇之感) / `zili`(自立倾向) → 结局分叉：忠汉到底=钟室之祸(史实)｜自立倾向高=另一种反思结局。
  - 项羽：`gangbi`(刚愎) / `yi`(义) / `renxin`(人心) → 越刚愎、越失义，垓下越孤。
  - 刘邦：`ren`(能屈) / `yong`(用人) / `caiji`(猜忌) → 影响功臣结局。
  - 张良：`wu`(悟) / `tui`(退隐倾向) → 与韩信"不知止足"对照。
- **可选小游戏预留**（`#minigame:<id>`，现默认判过）：背水一战`jingxing`、鸿门宴`hongmen`(疑心值博弈)、暗度陈仓`chencang`、圯上受书`yishang`。
- **幕界过场** `#actclear:<id>`："本幕通关"+史识小结+存档。
- **多结局**：每线除史实结局外，按累积状态给 1–2 个反事实结局（青月点评"史书里的他为何没这样"）。

3. 建/追加 `stories/inkStories/chuhan.ts`、`storylines/chuhan.ts`（`withSeries("chuhan", ...)`，注意现有旧引擎 hanxin/hongmen 也在 chuhan，迁移时并入）、`sceneAssets/chuhan.ts`、`achievements/chuhan.ts`，各 index 加一行。
