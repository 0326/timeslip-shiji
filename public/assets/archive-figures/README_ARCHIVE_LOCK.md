# 角色图鉴立绘锁定说明

`public/assets/archive-figures/` 是角色图鉴专用立绘目录，不能与剧情/对话立绘目录混用。

- 图鉴立绘路径：`/assets/archive-figures/<id>/full-default.jpg`
- 对话立绘路径：`/assets/figures/<id>/classical/portrait/full-default.png`
- 修改、重生成、修复对话立绘时，不要覆盖本目录。
- 图鉴入口由 `src/react-app/data/sceneAssets/archivePortraits.ts` 控制。
- 已锁定角色见 `ARCHIVE_PORTRAIT_LOCKED_IDS`。
